# 遥感与点云综合工具箱 · 更新下载

本仓库提供 Windows 安装包、便携版、更新说明和 SHA-256 校验文件，是工具箱的应用内更新源。

[下载最新版本](https://github.com/yaluncoco/RemoteSensingToolbox-Releases/releases/latest) · [源码与完整文档](https://github.com/yaluncoco/RemoteSensingToolbox)

从 v1.3.0 起，在软件左下角点击检查更新，选择“下载更新”，校验通过后点击“安装并重启”。下载支持取消和重试，任务运行时不会开始安装。

首次安装或从 v1.2.0 及更早版本升级，需要先运行新版安装包一次。之后可直接在软件内更新。

本仓库不存放源码和访问令牌。开发与问题反馈请前往源码仓库。
